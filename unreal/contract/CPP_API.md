# Walk the Archive — C++ API (module `WalkTheArchive`)

Generated from the headers in `WalkTheArchive/Source/WalkTheArchive/Public/`. Implementers write the matching
`Private/<Area>/*.cpp`; the editor Python and reviewers rely on the names below. Every reflected type uses the
`WTA` prefix and `WALKTHEARCHIVE_API`. Categories are `"WTA"` unless shown. `BP` = `UFUNCTION(BlueprintCallable)`,
`BPpure` = `UFUNCTION(BlueprintPure)`, `UP` = `UPROPERTY`. Include as `#include "Area/File.h"`.
Shadowing is a compile error (UE builds treat it as one): parameters and locals never reuse a member name of the class or its engine parents
(`Slot` in widgets, `Controller` in pawns, `Character`/`Pawn` in controllers, `Owner` and `Layers` in actors, `Run` in the play test); setters take `In<Name>`.

## Core
### `UWTASettings : UDeveloperSettings` (`Core/WTASettings.h`)
`UCLASS(Config=Game, DefaultConfig, meta=(DisplayName="Walk the Archive"))`, section `[/Script/WalkTheArchive.WTASettings]`.
- `static const UWTASettings* Get()`; `GetCategoryName()` = "Game".
- `UP(Config, EditAnywhere) TSoftObjectPtr<UDataTable>` **Exhibits, Books, Sources, Galleries, Subjects, Rooms, Places, Tour, Staff, StaffRules, Facts, Lessons, Badges, Tokens, WaxScenes, Stations, Rides** — constructor defaults `/Game/WTA/Data/DT_<Name>.DT_<Name>`.
- `UP(Config) FString ClientName` ("XR Libraries") and `CampusTitle` ("Walk the Archive"): the intro menu's kicker (`<CLIENTNAME> CAMPUS`) and title; `build_client.py` writes them into DefaultGame.ini from the client pack (`clients/<name>/campus.json`).
- `UP(Config) FWTAView SpawnView` (default (0,-70,162) yaw -90 pitch 1.146 valid), `FString SaveSlotName = "WalkTheArchive"`, `float ToastSeconds = 3.4`, `float HintSeconds = 6`, `bool bShowIntroMenu = true`.
- Lost Stories (category "Lost Stories"): `UP(Config) FString WhisperFolder` (whisper-cli and a `ggml-*.bin` model; empty = the `WTA_WHISPER` environment variable, else `<Project>/ThirdParty/whisper`, which `Tools/win/get_whisper.ps1` fills), `bool bStoriesNeedReview = true` (a new story waits in `Saved/Stories/New` until a librarian moves its two files into `Saved/Stories/Wall`; off, it goes straight on the wall), `float StoryMaxSeconds = 300` (a recording stops itself there).

### `AWTAGameMode : AGameModeBase` (`Core/WTAGameMode.h`)
Constructor: `DefaultPawnClass = AWTACharacter`, `PlayerControllerClass = AWTAPlayerController`, `GameStateClass = AWTAGameState`, `PlayerStateClass = AWTAPlayerState`, `HUDClass = AHUD` (the plain one: it draws nothing; with none the engine logs a failed spawn per player).
`StartPlay()` override: `BuildNavigationIfEmpty(GetWorld())`.
`static void BuildNavigationIfEmpty(UWorld*)`: when the default `ARecastNavMesh` uses `RuntimeGeneration=Dynamic` and has no active tiles (the headless setup run cannot build it: the editor holds its async-load navigation lock), calls `UNavigationSystemV1::Build()` once, so click-to-walk and the tour walk instead of teleporting. A NavMesh built and saved in the editor is kept. A guided visit's visitor machine (no game mode) calls it from `AWTAGameState::BeginPlay` and `UWTAVisitSubsystem`'s tick.
`PostLogin(APlayerController*)` (before Super, which spawns the pawn): the machine's own player gets `bGuide = (NM_ListenServer)`, `Slot 0`; a joining visitor the lowest free slot from 1 (log `WTA_VISIT joined slot n`). `Logout` logs `WTA_VISIT left slot n` (remote visitors only). `SpawnDefaultPawnAtTransform_Implementation`: as the engine's, but `AdjustIfPossibleButAlwaysSpawn` (no PlayerStart: every pawn starts at the world origin, where the guide may stand, and `OnPossess` then moves it).

### `AWTAGameState : AGameStateBase` (`Core/WTAGameState.h`)
Guided visits share this from the guide's machine (the listen server). `UP(ReplicatedUsing=OnRep_Tour) int32 TourStop=-1, TourSerial=0`; `UP(ReplicatedUsing=OnRep_Gather) int32 GatherSerial=0`; `UP(Replicated) FVector GatherFloor; float GatherYaw`.
`void LeadStop(int32 Index)` and `void Gather(const FVector& Floor, float Yaw)` (authority only; bump the serial, `ForceNetUpdate`, log `WTA_VISIT lead stop` / `WTA_VISIT gather`). `BPpure AWTAPlayerState* GetGuide() const; int32 NumVisitors() const`.
`BeginPlay`: on a client, `AWTAGameMode::BuildNavigationIfEmpty` and `UWTAVisitSubsystem::NoteGatherSerial(GatherSerial)` (a gathering from before the visitor came is not a call). `OnRep_Tour` → `UWTAVisitSubsystem::HandleTourReplicated(TourStop, TourSerial)`; `OnRep_Gather` → `HandleGatherReplicated(GatherFloor, GatherYaw, GatherSerial)`.

### `AWTAPlayerState : APlayerState` (`Core/WTAPlayerState.h`)
`UP(Replicated) bool bGuide; int32 Slot` (0 the guide, 1.. visitors in the order they came; `AWTAGameMode::PostLogin`), protected `UP(Replicated) bool bNamed`.
`BPpure FLinearColor GetVisitColor() const` (brass for the guide, then twelve muted colours by slot); `BPpure FString GetVisitName() const` (the name given on the visit card, else "Guide" / "Visitor n"); `void SetVisitName(const FString&)` (server: trimmed, at most 24 characters); `BPpure bool IsNamed() const` (the person's own game sent a name: a visitor's game has loaded).

## Wiring summary (who calls whom)
- Actors → controller: `Execute_Interact(Actor, PC)` → `PC->OpenExhibit/OpenBook/OpenStation/OpenRide/OpenStaffChat`, `PC->GoToView`, `PC->ShowToast/ShowCaption`.
- Subsystems → controller: delegates only (`OnRoomChanged`, `OnBadgeAwarded`, `OnTokenCollected`, `OnTourChanged`); the controller updates the HUD.
- Widgets → controller: `GetOwningPlayer()` cast to `AWTAPlayerController` (`RunAction`, `StepExhibit`, `OpenBook`, `CloseTopPanel`) and the subsystems' static `Get(this)`.
- Controller → character: `GetWTACharacter()->WalkTo/TeleportToView/AddMoveInput/SetSprinting/Jump`.
- Config needed outside C++: `DefaultEngine.ini` `GlobalDefaultGameMode=/Script/WalkTheArchive.WTAGameMode`; `DefaultInput.ini` keeps `DefaultPlayerInputClass=/Script/EnhancedInput.EnhancedPlayerInput` and `DefaultInputComponentClass=/Script/EnhancedInput.EnhancedInputComponent`; `DefaultGame.ini` `[/Script/WalkTheArchive.WTASettings]` table paths.
